# Cérvix-AI

Prototipo web académico que analiza imágenes públicas y desidentificadas de citología, colposcopia e histología del cuello uterino.

## Objetivo

Permitir cargar una imagen, validarla, preprocesarla y analizarla con modelos de inteligencia artificial, mostrando una categoría con su nivel de confianza y una visualización del resultado.

> ⚠️ Proyecto con fines académicos. No entrega diagnósticos definitivos ni debe usarse para decisiones clínicas.
